# Avisos de terceros

La maqueta 3D, el marcador y la interfaz se crearon para este prototipo; no incorporan modelos 3D de terceros.

Los archivos JavaScript de `vendor/` incluyen:

- **A-Frame 1.5.0** — [proyecto](https://github.com/aframevr/aframe), licencia MIT. Aviso completo: `vendor/LICENSE-aframe.txt`.
- **MindAR 1.2.5** — [proyecto](https://github.com/hiukim/mind-ar-js), licencia MIT. Aviso completo: `vendor/LICENSE-mindar.txt`.

La hoja de estilos solicita **DM Sans** y **Space Grotesk** desde Google Fonts; las fuentes no se incluyen en el repositorio. Si el servicio no responde, la interfaz usa Arial.
